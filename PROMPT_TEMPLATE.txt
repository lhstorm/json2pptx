## Critical JSON Structure Rules

1. **Always include** presentation_metadata with theme colors
2. **Start with title_slide** (slide_number: 1)
3. **End with thank_you** for formal presentations
4. **CRITICAL: Use "title" field** at slide level for ALL slides except title_slide
5. **Content structure**: Put "title" inside content object for most slide types
6. **Chart data**: Use "data" (not chart_data) with "labels" and "datasets" arrays
7. **Chart options**: Use "options" (not chart_options) for legend and grid settings
8. **Images**: Use "image" field (not image_path) for all image references
9. **Quotes**: Use "attribution" field (not author) for quote source
10. **Consistent numbering**: Start from 1, no gaps
11. **Speaker notes**: Include for important slides
12. **Hierarchy levels**: Use 0, 1, 2 for bullet points and numbered lists  
13. **Never leave content empty** - always provide meaningful text and data

## Generation Guidelines

When generating JSON based on user requirements:

1. **Slide Type Selection**:
   - Use bullet_points for lists and key points
   - Use chart_slide for data visualization (specify chart_type: bar/line/pie/area)
   - Use data_table for structured data
   - Use comparison_table for side-by-side comparisons
   - Use text_image_left/right when images enhance content
   - Use timeline for chronological information
   - Use process_flow for step-by-step processes
   - Use content_two_column/three_column for comparisons or categorization
   - Use icon_points for benefits or features with visual elements
   - Use team_slide for introducing people
   - Use quote_slide for testimonials or inspirational content

2. **Content Guidelines**:
   - Keep titles under 60 characters
   - Use bullet points effectively with proper hierarchy (levels 0, 1, 2)
   - Include speaker_notes for complex slides
   - Set appropriate durations: 30s for title, 15-20s for content slides
   - Use descriptive image keywords in URLs

3. **Structure Requirements**:
   - CRITICAL: Every slide except title_slide MUST have a "title" field at the root level
   - All slides need proper slide_number sequencing (1, 2, 3, etc.)
   - Include presentation_metadata with appropriate theme colors
   - Use consistent formatting throughout
   - Never create slides with empty or missing content
   - Always provide meaningful text for all content fields
